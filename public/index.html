◇ Cromaticidade CIE 1931 xy
Sobre esta amostragem ▾

Cada ponto é um pixel amostrado do frame mais recente, na cor real dele, convertido para coordenadas de cromaticidade — mostra se o conteúdo está de fato usando um gamut mais amplo que o Rec.709/sRGB. Não acumula histórico: a cada nova amostragem os pontos são substituídos pelos do frame atual.

    Análise de qualidade — PSNR / SSIM com referência
    
          
    Requer uma referência (mezzanine) do mesmo conteúdo-fonte usado para
            codificar o stream — comparar contra um vídeo diferente produz números sem significado (mede diferença

            da Netflix exige libvmaf via ffmpeg, offline — fora do escopo do navegador).

Stream Inspector

Inspeção de transmissões em streaming HLS e DASH com metadados de vídeo, áudio, legendas, DRM, bem como uma seção de telemetria em tempo real.

Exemplos:

Para URLs do YouTube (youtube.com/watch, youtu.be, lives): requer yt-dlp instalado na máquina que roda o server.js (pip install yt-dlp). O sistema apenas chama o yt-dlp como resolvedor local — uso sujeito aos Termos do YouTube.

    Análise de qualidade — PSNR / SSIM com referência
    
      
    Requer uma referência (mezzanine) do mesmo conteúdo-fonte usado para
        codificar o stream — comparar contra um vídeo diferente produz números sem significado (mede diferença
        de conteúdo, não de qualidade). Isto é PSNR/SSIM reais; não é VMAF (o modelo certificado
        da Netflix exige libvmaf via ffmpeg, offline — fora do escopo do navegador).

    Cromaticidade CIE 1931 xy — frame atual (instantâneo)
    
      
    Cada ponto é um pixel amostrado do frame mais recente, na cor real dele, convertido para
        coordenadas de cromaticidade — mostra se o conteúdo está de fato usando um gamut mais amplo que o
        Rec.709/sRGB, ou se na prática fica todo contido nele. Não acumula histórico: a cada nova amostragem
        os pontos são substituídos pelos do frame atual.
